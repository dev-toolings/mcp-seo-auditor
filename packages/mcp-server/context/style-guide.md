# Style Guide

Writing rules and formatting conventions for all content.

## Sentence & Paragraph Rules

- **Max sentence length:** 25 words (aim for 15-20)
- **Max paragraph length:** 4 sentences
- **Readability target:** Flesch 60+ (EN) / Kandel-Moles 50+ (FR)

## Formatting

- Use H2 for main sections, H3 for subsections
- One idea per paragraph
- Use bullet lists for 3+ related items
- Bold key terms on first use
- Include a TL;DR or key takeaway at the top of long articles

## Vocabulary

### Preferred Terms

| Avoid           | Use instead     |

| utilize         | use             |
| leverage        | use / apply     |
| implement       | set up / add    |
| in order to     | to              |
| at this time    | now             |

### Forbidden Words

- "Simply" (dismissive)
- "Obviously" (condescending)
- "Just" when minimizing effort
- [Add your own forbidden words]

## SEO Writing Rules

- Include the primary keyword in the H1 and first 100 words
- Use semantic variations naturally throughout the text
- Write meta descriptions between 140-155 characters
- Title tags: 50-60 characters, keyword near the beginning
- One H1 per page, logical H2/H3 hierarchy
