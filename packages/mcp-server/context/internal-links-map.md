# Internal Links Map

Key pages and their linking strategy. Used by content generation to insert relevant internal links.

## Pillar Pages (highest priority)

These pages should receive the most internal links:

| Page                | URL                          | Anchor Text Suggestions               |
| ------------------- | ---------------------------- | --------------------------------------|
| [Product Overview]  | /product                     | "our platform", "product features"    |
| [Pricing]           | /pricing                     | "see pricing", "plans and pricing"    |
| [Blog Hub]          | /blog                        | "on our blog", "read more articles"   |

## Category / Topic Clusters

### [Topic Cluster 1 — e.g., "SEO Basics"]

- **Hub page:** /blog/seo-guide (link from all cluster articles)
- **Spoke pages:**
  - /blog/what-is-seo — anchor: "what is SEO"
  - /blog/keyword-research — anchor: "keyword research guide"
  - /blog/on-page-seo — anchor: "on-page optimization"

### [Topic Cluster 2 — e.g., "Technical SEO"]

- **Hub page:** /blog/technical-seo-guide
- **Spoke pages:**
  - /blog/site-speed — anchor: "improve site speed"
  - /blog/structured-data — anchor: "structured data markup"

## Linking Rules

- Every blog post must link to at least 1 pillar page
- Link to the relevant topic cluster hub from every spoke article
- Use descriptive anchor text (not "click here" or "read more")
- Max 3-5 internal links per 1000 words
- Prioritize contextual links within body text over sidebar/footer links

## Conversion Pages

These pages should be linked when the context is right (CTA opportunities):

- /demo — "book a demo", "see it in action"
- /signup — "get started free", "try it today"
- /contact — "talk to our team", "get in touch"
